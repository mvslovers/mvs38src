# The four proposed merges: none of them, and why — 2026-09-16

Mike delegated the call. All four were examined before deciding, and **all four
sources turn out to carry something their target does not.** A merge that drops a
measurement or a correction is worse than 21 redundant lines.

| proposed | declined because |
|---|---|
| `parity-by-commit.md` → `igc018-macro-path.md` | It is **not** a duplicate. It carries a three-commit parity table (`b799ae0` 5,379 / `b67af3d` 5,415 / `fd287d3` 5,427) that exists nowhere else, and the observation that **two days of cc370 merges — +36 and +12, none lost — were never recorded in TODO.md.** `igc018-macro-path.md` covers only the one-module `IGC018` difference. |
| `build-vs-original.md` → `build-vs-original-tk5.md` | It carries **its own correction**: *"What I wrote here first — that every difference is a length difference … is false."* The TK5 page **cites this document for that correction** — *"corrected in the MVS/CE document"* — so merging would either move the correction and break the citation, or drop it. It also holds the detailed `ERRORS` table (1,723 / 1,497 / 405 / 468) and the `ICHRIN00` line that settles it. |
| `cc370-cases.md` → `what-is-left.md` | The target was **itself superseded** on 2026-09-16. Merging into a superseded page moves content one step further from the reader. |
| `open-decisions.md` → `../TODO.md` | TODO records **what was decided**; this page records **how the question stood before it was**. Folding it in loses the dated trail of a decision's reasoning, which is the one thing a project that lies dormant needs most. |

**The general rule this produced, and it is worth keeping:** a document proposed
for merging on the grounds that it *overlaps* another must be read for what it
holds *alone*. Three of these four overlap substantially and not one of them is
contained.

**Nothing was merged and nothing was deleted.** All four keep their banners, which
is what makes them navigable without making them authoritative.
